# Выпадающий список `<select>` в JavaScript

В калькуляторе вы читали числа из полей ввода. Теперь добавим выпадающий список, чтобы пользователь мог выбрать валюту из готовых вариантов.

## Как устроен `<select>`

Тег `<select>` создаёт список, а каждый `<option>` добавляет в него один вариант.

```html
<label for="currency">Валюта</label>
<select id="currency">
  <option value="RUB">Рубли</option>
  <option value="USD">Доллары</option>
  <option value="EUR">Евро</option>
  <option value="KZT">Тенге</option>
</select>
```

Внутри `<option>` написано то, что видит пользователь. Атрибут `value` задаёт значение, которое получит JavaScript. Например, при выборе «Доллары» свойство `select.value` вернёт строку `"USD"`. По умолчанию выбран первый пункт.

## Пример. Показываем выбранную валюту

Сохраните этот пример в `example.html` и откройте файл в браузере. Выберите валюту и нажмите кнопку.

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Выбор валюты</title>
</head>
<body>
  <label for="currency">Валюта</label>
  <select id="currency">
    <option value="RUB">Рубли</option>
    <option value="USD">Доллары</option>
    <option value="EUR">Евро</option>
    <option value="KZT">Тенге</option>
  </select>

  <button id="show">Показать</button>
  <p id="result"></p>

  <script>
    const currency = document.getElementById('currency');
    const button = document.querySelector('#show');
    const result = document.getElementById('result');

    button.addEventListener('click', () => {
      result.innerHTML = 'Выбрана валюта ' + currency.value;
    });
  </script>
</body>
</html>
```

`currency` хранит сам элемент `<select>`, а `currency.value` — код выбранного пункта. Читаем `.value` внутри обработчика клика, чтобы каждый раз получать текущий выбор.

## Задание. Конвертер валют

Сделайте страницу `index.html`, на которой можно ввести сумму, выбрать две валюты и перевести сумму из одной валюты в другую.

1. Добавьте поле суммы `<input type="number">`, два списка «Из какой валюты» и «В какую валюту», кнопку «Перевести» и абзац для результата. В обоих списках должны быть рубли, доллары, евро и тенге. Задайте спискам разные `id`, например `fromCurrency` и `toCurrency`.
2. При нажатии на кнопку прочитайте сумму и значения обоих списков. Если поле суммы пустое или сумма отрицательная, выведите «Введите сумму от 0» и завершите обработчик. Проверьте пустую строку до вызова `Number()`, потому что `Number('')` даёт `0`.
3. С помощью `if / else if` определите курс каждой из двух выбранных валют по таблице. Умножьте сумму на курс исходной валюты, чтобы получить рубли. Затем разделите полученные рубли на курс целевой валюты.
4. Выведите результат через `innerHTML`, например `50 USD = 45.00 EUR`. Чтобы показать два знака после точки, используйте `resultAmount.toFixed(2)`, где `resultAmount` — рассчитанное число.

### Учебные курсы

| Валюта | Код | Сколько рублей стоит 1 единица |
| --- | --- | ---: |
| Рубль | `RUB` | 1 |
| Доллар | `USD` | 90 |
| Евро | `EUR` | 100 |
| Тенге | `KZT` | 0.2 |

Курсы условные. Например, для перевода `50 USD` в евро сначала получаем `50 × 90 = 4500` рублей, затем `4500 ÷ 100 = 45` евро.

### Проверьте в браузере

| Сумма | Из | В | Что должно получиться |
| --- | --- | --- | --- |
| 4500 | RUB | USD | `4500 RUB = 50.00 USD` |
| 50 | USD | EUR | `50 USD = 45.00 EUR` |
| 500 | KZT | RUB | `500 KZT = 100.00 RUB` |
| 10 | EUR | EUR | `10 EUR = 10.00 EUR` |
| 0 | RUB | KZT | `0 RUB = 0.00 KZT` |
| Пустое поле или `-10` | Любая | Любая | `Введите сумму от 0` |

Поменяйте валюту и снова нажмите «Перевести». Результат должен обновиться без перезагрузки страницы.
